# 我们的小日子

一款适合在微信内打开的情侣日常 50 件小事 H5 大转盘。项目为纯前端实现，不依赖框架、接口或数据库。

## 已实现

- 50 件情侣日常小事，每件都有分类和行动说明
- 转盘随机抽取，并可自动跳过已经完成的项目
- 完成盖章、全部/待完成/已完成清单筛选
- 进度自动保存在当前手机浏览器的 `localStorage`
- 微信内分享引导，以及系统分享/复制链接降级
- 竖屏、横屏、安全区域、键盘操作和减少动态效果适配

## 本地预览

在当前目录执行：

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173`。

## 放到微信里使用

这是微信内可打开的 H5，而不是需要审核上架的原生微信小程序。上线步骤如下：

1. 将本目录中的 `index.html`、`styles.css`、`tasks.js`、`app.js` 部署到可公开访问的静态网站。
2. 为网站启用 HTTPS；微信好友需要访问部署后的公网 HTTPS 地址，不能访问本机的 `127.0.0.1`。
3. 把该地址发到微信，用户点开即可直接玩。

顶部分享按钮在微信内会提示用户使用右上角菜单分享。若需要自定义微信分享卡片的标题、缩略图和描述，还需要已认证公众号的 JS-SDK 配置与后端签名接口；当前零后端版本没有伪造这项能力。

## 数据说明

完成进度只保存在当前设备的当前浏览器中。清理微信缓存或更换手机后不会自动同步；若需要情侣双方共享同一份实时进度，需要再接入登录和云端存储。

任务文案集中在 `tasks.js`，可直接修改标题、分类和说明，但请保持 `id` 为 1 到 50 且不重复。
